| Prefix | Full form                  | Purpose                                                                                                 | Example                                |
| ------ | -------------------------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| FR     | Functional Requirement     | Identifies a feature or capability the application must provide.                                        | `FR-01`: User Authentication         |
| TI     | Technical Indicator        | Identifies an individual technical indicator used for stock analysis.                                   | `TI-01`: Simple Moving Average (SMA) |
| NFR    | Non-Functional Requirement | Identifies quality attributes and technical constraints such as security, performance, and reliability. | `NFR-01`: Client-Server Architecture |
| OOS    | Out of Scope               | Identifies features excluded from the MVP and considered for future releases.                           | `OOS-01`: Investment Goal Planning   |
| AD     | Assumption/Decision        | Identifies assumptions or open decisions that need confirmation.                                        | `AD-01`: Authentication Requirement  |
