Stakeholder feature blueprint · MVP

Real-Time Stock Market Analyzer

A focused NSE stock analysis dashboard for browsing daily market data, exploring technical indicators, tracking manually entered positions, and viewing Moving Average Crossover signals.

Product Lead: Pavan Market: NSE-listed stocks MVP universe: curated Nifty 100-style list Data: daily historical / end-of-day

Core MVP Features

The features included in the first release.

🔐
Account

User Authentication

  • Sign in to a persistent user account
  • Keep each user's saved positions across visits
  • Show each user their own portfolio records
🔎
Discover

NSE Stock Browser

  • Browse a curated Nifty 100-style stock universe
  • View stock name, symbol, latest available price, and daily change
  • Open a selected stock's detail view
📈
Analyze

Daily Price Chart

  • View historical daily price movement
  • Display Open, High, Low, Close, and Volume (OHLCV) history
  • Load data when a stock is first viewed and refresh at most once per day
🧭
Analyze

Technical Indicators

Toggle indicators on or off for visual chart analysis.

  • Simple Moving Average (SMA)
  • Exponential Moving Average (EMA)
  • Relative Strength Index (RSI)
  • Bollinger Bands (BB)
  • MACD
  • Stochastic Oscillator
  • Average True Range (ATR)
  • Volume Weighted Average Price (VWAP)
  • On-Balance Volume (OBV)
  • Parabolic SAR
💼
Portfolio

Manual Position Management

  • Add a position using stock, quantity, buy price, and buy date
  • Save each purchase as a separate lot
  • View and maintain saved position entries
💹
Portfolio

Per-Position Profit & Loss

  • Compare buy price with the latest available stock price
  • Display profit or loss as an amount and percentage
  • Show P&L separately for each lot of a holding
⚙️
Strategy

Moving Average Crossover

  • Apply the MVP's single supported strategy to a stock
  • Choose the moving-average period, such as 50 days
  • Generate a buy signal when price crosses above the moving average
  • Generate a sell signal when price crosses below the moving average
🎯
Strategy

Signal Visualization

  • Mark buy and sell signals on the chart at their historical dates
  • Show signal type, date, and signal price in a signal table
  • Calculate signals from available historical price data when requested
🔄
Data

On-Demand Data & Calculations

  • Fetch historical data when a stock is viewed
  • Refresh stock history at most once per day when revisited
  • Calculate selected indicators and strategy signals on demand

Key Product Behaviors

Important feature rules visible to stakeholders.

✓Technical indicators support visual analysis; they do not independently create buy/sell signals in the MVP.
✓Position records are saved to the signed-in user's account.
✓Every purchase entry remains a separate lot rather than being automatically averaged.
✓P&L is shown per lot using the latest available price in the app's data.
✓Price history and strategy signals are retrieved or calculated on demand.
✓The MVP uses daily/end-of-day data, not a streaming live feed.
